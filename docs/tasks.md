# משימות פתוחות

## משימות שלך (לא של הקוד)
- [ ] **לדבר עם דני, שלישות בבאח״ד צנחנים:** להבין מה המגבשים ממלאים בפועל, והאם כבר יש אפליקציה או מערכת שהם משתמשים בה. שאלות מוכנות ב-[`interview-guide.md`](interview-guide.md) (חלק משותף וכיוון ב׳). מה לרשום: איפה רושמים, אילו שדות, כמה זמן זה לוקח, ומי רואה.
- [ ] לשים לב במיוחד לשלוש שאלות: מי ממלא כל שדה (מ״כ / מ״מ / מגבש), מה חסר להם היום, ומה אסור להם להחזיק מחוץ למערכת הרשמית.

## בצד הקוד
- [x] תמונת מצב לפי יחידה, ובתוכה לפי פלוגה וצוות
- [x] סגל הכשרה: מ״כ, מ״מ, מ״פ
- [x] דף מגבש: חסר מידע מסומן בצבע
- [x] מילוי הנתונים באחריות המ״מ, והמ״כ מזין רק מדדים והגעה
- [x] מעבר ישיר ממסך למסך (בדיקת הדחה מהתיק לחדר ההדחה, כרטיסי תמונת המצב לרשימה מסוננת)
- [x] חיילים בהכשרה: ייצוא לאקסל וסינון לפי יחידה, תפקיד, פלוגה ועוד
- [x] הוסר הלב של המועדפים
